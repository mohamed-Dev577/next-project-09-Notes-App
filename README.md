📝 Notes App
📌 وصف المشروع

تطبيق بسيط لإضافة الملاحظات وعرضها وحذفها باستخدام Next.js وReact. يساعد المشروع على التدريب العملي على إدارة الحالة والتعامل مع الأحداث والمصفوفات في React.

🛠️ التقنيات المستخدمة
Next.js
React
JavaScript
JSX
✨ مميزات المشروع
إضافة ملاحظات جديدة.
عرض جميع الملاحظات في قائمة.
حذف الملاحظات بشكل منفصل.
منع إضافة الملاحظات الفارغة أو المكوّنة من مسافات فقط.
تفريغ حقل الكتابة تلقائيًا بعد إضافة الملاحظة.
🧠 المفاهيم التي تم تطبيقها
useState لإدارة الحالة.
onChange للتعامل مع تغييرات حقل الإدخال.
onClick لتنفيذ الأحداث عند الضغط على الأزرار.
map() لعرض الملاحظات.
filter() لحذف الملاحظات.
Spread Operator لإضافة الملاحظات إلى المصفوفة.
trim() للتحقق من محتوى الملاحظة.
📂 تشغيل المشروع
افتح مجلد المشروع في Visual Studio Code.
افتح Terminal داخل المجلد.

ثبّت الاعتماديات إذا لم تكن مثبّتة باستخدام:

npm install

شغّل المشروع باستخدام:

npm run dev

افتح العنوان المحلي الذي يظهر في Terminal، وغالبًا يكون:

http://localhost:3000

👨‍💻 المطوّر

تم تنفيذ المشروع ضمن سلسلة مشاريع تدريبية لتطوير مهارات Front-End باستخدام React وNext.js.
